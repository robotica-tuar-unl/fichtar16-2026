1.1 Modificar el nodo de control

Modificar el nodo del ejercicio 8 del entregable 1 para añadir una funcionalidad de seguridad con el siguiente esquema:

  1. Al recibir un mensaje de tipo geometry_msgs/Twist a través de un topic llamado cmd_vel almacena el valor del clock utilizando la función de rclpy
# Estampa de tiempo en segundos (con decimales)
t = self.get_clock().now().nanoseconds / 1e9
  1. Si luego de una cantidad de milisegundos determinada por el parámetro timeout no recibe un nuevo comando, envía un comando de detención a las ruedas (velocidad angular igual a cero).
# Obtener el tiempo actual
t_now = self.get_clock().now().nanoseconds / 1e9

if t_now > (t + timeout):
  # Detenerse
  # ..
  1. Si recibe un nuevo mensaje de Twist, refresca el valor del clock volviendo al paso 2.

La comprobación del timeout debe ser asincrónica del procesamiento de los mensajes recibidos, por lo que se debe implementar al menos un Timer

Probar la modificación del nodo utilizando la simulación

  • Enviar comandos de Twist desde consola con valores distinto de cero.
  • Utilice la opción --once o termine la ejecución mediante Ctrl+C.
  • El robot debería deternerse luego de cumplido el timeout.
