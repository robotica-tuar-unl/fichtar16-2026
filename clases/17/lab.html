1.1 Algoritmo ICP “punto-a-plano”

A) Función principal callback

  1. Convertir de coordenada polar a cartesiana
  2. Obtener las normales utilizando la función provista compute_normals_segments
  3. Si es el primer mensaje, guardar los puntos y las normales, y terminar
  4. Si no, obtener la transformación
  5. Si no convergió, terminar
  6. Si convergió, acumular pose y publicar odometría
  7. Actualizar puntos y normales para la próxima ejecución

B) Bucle ICP

  1. Inicializar el estado (transformación, convergencia, error anterior, etc.)
  2. Construir el árbol para búsqueda de vecino más cercano
  3. Bucle hasta \(N\) iteraciones:
    • Dado el conjunto de puntos actual, buscar las correspondencias
    • Si no hay suficientes correspondencias, terminar sin convergencia
    • Si hay, calcular el error de la correspondencia
    • Estimar la transformación y transformar los puntos
    • Acumular la transformación
    • Si el cambio del error es menor que un umbral, cortar el bucle (convergió)
    • Si no, actualizar el último error y volver al inicio
  4. Retornar la rotación y la traslación, el estado de convergencia y el error (opcional)

C) Estimación del movimiento

  • Construir la matriz \(\mathbf{A}\) y el vector \(\mathbf{b}\):

\[ \mathbf{A} = \begin{bmatrix} -\eta_{\mathbf{p}_1,x} & -\eta_{\mathbf{p}_1,y} & \eta_{\mathbf{p}_1,x}q_{1,y} - \eta_{\mathbf{p}_1,y}q_{1,x} \\ -\eta_{\mathbf{p}_2,x} & -\eta_{\mathbf{p}_2,y} & \eta_{\mathbf{p}_2,x}q_{2,y} - \eta_{\mathbf{p}_2,y}q_{2,x} \\ \vdots & \vdots & \vdots \\ -\eta_{\mathbf{p}_N,x} & -\eta_{\mathbf{p}_N,y} & \eta_{\mathbf{p}_N,x}q_{N,y} - \eta_{\mathbf{p}_N,y}q_{N,x} \end{bmatrix} \]

\[ \mathbf{b} = \begin{bmatrix} \boldsymbol{\eta}_{\mathbf{p}_1}^{T} (\mathbf{p}_1-\mathbf{q}_1) \\ \boldsymbol{\eta}_{\mathbf{p}_2}^{T} (\mathbf{p}_2-\mathbf{q}_2) \\ \vdots \\ \boldsymbol{\eta}_{\mathbf{p}_N}^{T} (\mathbf{p}_N-\mathbf{q}_N) \end{bmatrix} \]

import numpy as np

def fit_segment_fast(points, start, max_error, max_range_jump, min_points=3):
    N = points.shape[0]

    count = 1

    sum_x, sum_y = points[start]

    sum_xx = points[start, 0] ** 2
    sum_xy = points[start, 0] * points[start, 1]
    sum_yy = points[start, 1] ** 2

    best_normal = None
    best_error = np.inf
    best_end = start

    for j in range(start + 1, N):

        # Discontinuidad
        dx = points[j, 0] - points[j - 1, 0]
        dy = points[j, 1] - points[j - 1, 1]

        if dx * dx + dy * dy > max_range_jump ** 2:
            break

        # Añadir punto
        x = points[j, 0]
        y = points[j, 1]

        count += 1

        sum_x += x
        sum_y += y

        sum_xx += x * x
        sum_xy += x * y
        sum_yy += y * y

        # Centroide
        mean_x = sum_x / count
        mean_y = sum_y / count

        # Covarianza
        cxx = sum_xx / count - mean_x * mean_x
        cxy = sum_xy / count - mean_x * mean_y
        cyy = sum_yy / count - mean_y * mean_y

        # Autovalor menor de matriz 2x2
        trace = cxx + cyy
        diff = cxx - cyy

        lambda_min = (
            trace -
            np.sqrt(diff * diff + 4.0 * cxy * cxy)
        ) * 0.5

        # Error RMS perpendicular
        error = np.sqrt(max(lambda_min, 0.0))

        if error > max_error:
            break

        # Dirección principal
        phi = 0.5 * np.arctan2(
            2.0 * cxy,
            cxx - cyy
        )

        # Normal
        normal = np.array([
            -np.sin(phi),
             np.cos(phi)
        ])

        # Orientar hacia el LiDAR
        if (normal[0] * (-mean_x) + normal[1] * (-mean_y)) < 0:
            normal = -normal

        best_normal = normal
        best_error = error
        best_end = j

    if best_end - start + 1 < min_points:
        return start, None, np.inf

    return best_end, best_normal, best_error

def compute_normals_segments(points, max_error=0.05, max_range_jump=0.5, min_points=3):
    """
    Calcula normales por segmentos lineales consecutivos.

    Parameters
    ----------
    points : ndarray, shape (N, 2)
        Nube de puntos 2D

    Returns
    -------
    normals : ndarray, shape (N, 2)
        Vector normal asociado a cada punto
    confidence : ndarray, shape (N,)
        Confianza asociada a cada punto
    segment_ids : ndarray, shape (N,)
        Segmento asociado a cada punto (-1 si no se pudo asociar)
    """

    N = points.shape[0]

    normals = np.zeros_like(points)
    confidence = np.zeros(N)
    segment_ids = -np.ones(N, dtype=int)

    start = 0
    segment_id = 0

    while start < N:
        end, normal, error = fit_segment_fast(
            points,
            start,
            max_error=max_error,
            max_range_jump=max_range_jump,
            min_points=min_points
        )

        # No se pudo formar un segmento
        if normal is None:
            start += 1
            continue

        # Asignar la misma normal a todos los puntos
        normals[start:end + 1, :] = normal

        # Confidence (simplificada) basada en el error
        conf = np.exp(-error / max_error)

        confidence[start:end + 1] = conf
        segment_ids[start:end + 1] = segment_id

        segment_id += 1

        # Continuar después del segmento
        start = end + 1

    return normals, confidence, segment_ids
