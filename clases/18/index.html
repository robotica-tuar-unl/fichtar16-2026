Mapeo

Dadas todas las lecturas del LiDAR y sabiendo desde dónde se capturó cada una, ¿qué tan probable es un mapa del entorno?

  • Por ejemplo: supongamos que el robot recorre un pasillo
  • En cada posición, el LiDAR mide distancias hacia las paredes y otros objetos
  • Una medición aislada aporta información parcial, pero al combinar las mediciones tomadas desde diferentes posiciones, podemos construir una representación más completa del entorno

Mapeo

\[ p(\mathbf{m} \mid \mathbf{z}_{1:t}, \mathbf{x}_{1:t}) \]

Esta expresión representa la distribución de probabilidad del mapa \(\mathbf{m}\) dadas todas las mediciones del sensor y todas las poses del robot hasta el instante \(t\)

Podemos definir la notación de la siguiente manera:

  • \(\mathbf{m}\) : el mapa del entorno que queremos construir
  • \(\mathbf{z}_{t}\) : la medición del sensor en el instante \(t\)
  • \(\mathbf{z}_{1:t}\) : el conjunto de todas las mediciones desde el instante inicial hasta \(t\)
  • \(\mathbf{x}_{t}\) : la pose del robot en el instante \(t\)
  • \(\mathbf{x}_{1:t}\) : el conjunto de poses del robot durante todo el recorrido desde el instante inicial hasta \(t\)
  • \(p(\cdot)\): representa una distribución de probabilidad

Mapeo

Problemas: 1) Dimensionalidad

  • Se divide el entorno en una grilla y para simplificar, suponemos inicialmente que cada celda solo puede estar en uno de dos estados:
    • Ocupada: hay un obstáculo en esa región
    • Libre: no hay un obstáculo en esa región
  • Si cada celda tiene dos estados posibles, una grilla de \(N\) celdas puede representar:

\[ N_{\text{mapas}}=2^N \]

  • Para un mapa de 10 celdas existen \(2^{10}=1024\) configuraciones
  • Pero si utilizamos una grilla de 100 o 1000 celdas:

\[ N_{\text{mapas}}= 2^{100} \approx 1.26765 \dots 10^{30} \]

Mapeo

Problemas: 1) Dimensionalidad

Si intentáramos representar explícitamente la probabilidad de cada mapa completo, tendríamos que almacenar o calcular una cantidad de valores que crece exponencialmente con el número de celdas


Problemas: 2) Error de odometía: el huevo o la gallina

  • Cuando el robot se mueve por su entorno, acumula errores de odometría, lo que reduce la precisión sobre la ubicación a la que se capturó la medición
  • Para disminuir el error puedo usar un mapa, pero para tener el mapa necesito la ubicación de las mediciones

Mapeo

Suposiciones para el desarrollo del algoritmo

  • Odometría conocida y perfecta pero mediciones de LiDAR con ruido

  • El escenario es estático y por lo tanto el mapa también (no hay objetos en movimientos)

  • El algorimo a implementar será Grillas de ocupación

Desarrollo

Dada una nueva medición, actualizamos la probabilidad de que una celda esté ocupada

\[ p(m_{i} = 1 \mid \mathbf{z}_{1:t}, \mathbf{x}_{1:t}) \]

  • Reexpresando \(\mathbf{z}_{1:t}\) como \(\mathbf{z}_{t}, \mathbf{z}_{1:t-1}\):

\[ p(m_{i} \mid \mathbf{z}_{t}, \mathbf{z}_{1:t-1}, \mathbf{x}_{1:t}) \]

  • y definiendo una condición auxiliar \(\mathbf{H}_t = \mathbf{z}_{1:t-1}, \mathbf{x}_{1:t}\)

\[ p(m_{i} \mid \mathbf{z}_{t}, \mathbf{H}_{t}) \]

Desarrollo

  • Aplicando la regla de Bayes condicional para poder calcular la probabilidad de que la celda esté ocupada teniendo en cuenta una nueva medición de LiDAR

\[ p(A \mid B, C) = \frac{p(B \mid A, C) ~p(A\mid C)}{p(B\mid C)} \]

  • Se obtiene:

\[ p(m_{i} = 1 \mid \mathbf{z}_{1:t}, \mathbf{x}_{1:t}) = \frac{p(\mathbf{z}_{t}\mid m_{i}, \mathbf{H}_{t}) ~p(m_{i}\mid \mathbf{H}_{t})}{p(\mathbf{z}_{t}\mid \mathbf{H}_{t})} \]

  • Recuperando la expresión orginal con \(\mathbf{H}_t = \mathbf{z}_{1:t-1}, \mathbf{x}_{1:t}\):

\[ p(m_{i} = 1 \mid \mathbf{z}_{1:t}, \mathbf{x}_{1:t}) = \frac{p(\mathbf{z}_{t}\mid m_{i}, \mathbf{z}_{1:t-1}, \mathbf{x}_{1:t}) ~p(m_{i} \mid \mathbf{z}_{1:t-1}, \mathbf{x}_{1:t})}{p(\mathbf{z}_{t} \mid \mathbf{z}_{1:t-1}, \mathbf{x}_{1:t} )} \]

Desarrollo

  • Reordenando se tiene:

\[ p(m_{i} = 1 \mid \mathbf{z}_{1:t}, \mathbf{x}_{1:t}) = \frac{ p(\mathbf{z}_{t} \mid m_{i}, \mathbf{z}_{1:t-1}, \mathbf{x}_{1:t}) ~p(m_{i} \mid \mathbf{z}_{1:t-1}, \mathbf{x}_{1:t}) } { p(\mathbf{z}_{t} \mid \mathbf{z}_{1:t-1}, \mathbf{x}_{1:t} ) } \]

  • Interpretación
\(p(m_{i} = 1 \mid \mathbf{z}_{1:t}, \mathbf{x}_{1:t})\) Creencia actual sobre la ocupación de la celda
\(p(\mathbf{z}_{t} \mid m_{i},\mathbf{z}_{1:t-1}, \mathbf{x}_{1:t})\) Qué tan compatible es la nueva medición con el estado de la celda (teniendo en cuenta la información anterior)
\(p(m_{i} \mid \mathbf{z}_{1:t-1}, \mathbf{x}_{1:t})\) Creencia que teníamos antes de incorporar la medición actual
\(p(\mathbf{z}_t \mid \mathbf{z}_{1:t-1}, \mathbf{x}_{1:t})\) Factor de normalización

Desarrollo

Simplificaciones

  • Si \(C\) es independiente de \(A\) dado \(B\), entonces \(C\) no provee información extra acerca de \(A\) luego de conocer \(B\):

\[ p(A \mid B, C) = p(A \mid B) \]

  • Dado que mediciones actuales solo dependen del estado actual y de la celda del mapa, y no de la medición, el término puede simplificarse:

\[ p(\mathbf{z}_{t} \mid \mathbf{x}_{1:t}, m_{i},\mathbf{z}_{1:t-1}) = p(\mathbf{z}_{t} \mid \mathbf{x}_{t}, m_{i}) \]

Desarrollo

Simplificaciones

  • También podemos afirmar que el estado actual sin las mediciones actuales no aportan información adicional acerca de la ocupación de la celda:

\[ p(m_{i} \mid \mathbf{z}_{1:t-1}, \mathbf{x}_{1:t}) = p(m_{i} \mid \mathbf{z}_{1:t-1}, \mathbf{x}_{1:t-1}) \]

  • Reemplazando ambas simplificaciones:

\[ \begin{align*} p(m_{i} \mid \mathbf{z}_{1:t}, \mathbf{x}_{1:t}) &= \frac{ p(\mathbf{z}_{t} \mid \mathbf{x}_{t}, m_{i}) ~p(m_{i} \mid \mathbf{z}_{1:t-1}, \mathbf{x}_{1:t-1}) } { p(\mathbf{z}_{t} \mid \mathbf{z}_{1:t-1}, \mathbf{x}_{1:t} ) } \\[1em] &= \frac{ 1 } { p(\mathbf{z}_{t} \mid \mathbf{z}_{1:t-1}, \mathbf{x}_{1:t} ) } ~p(\mathbf{z}_{t} \mid \mathbf{x}_{t}, m_{i}) ~p(m_{i} \mid \mathbf{z}_{1:t-1}, \mathbf{x}_{1:t-1}) \end{align*} \]

Desarrollo

  • Reescribimos:

\[ \underbrace{ p(m_{i} \mid \mathbf{z}_{1:t}, \mathbf{x}_{1:t}) }_{\text{b}_{(t)}(m_{i})} = \underbrace{ \frac{1}{ p(\mathbf{z}_{t} \mid \mathbf{z}_{1:t-1}, \mathbf{x}_{1:t} ) } }_{\eta_{t}} ~p(\mathbf{z}_{t} \mid \mathbf{x}_{t}, m_{i}) \underbrace{ ~p(m_{i} \mid \mathbf{z}_{1:t-1}, \mathbf{x}_{1:t-1}) }_{\text{b}_{(t-1)}(m_{i})} \]

de manera que:

\[ \text{b}_{(t)}(m_{i}) = \eta_{t} ~p(\mathbf{z}_{t} \mid \mathbf{x}_{t}, m_{i}) ~\text{b}_{(t-1)}(m_{i}) \]


Para actualizar una celda no necesitamos volver a procesar todo el historial, nos alcanza con la creencia que ya teníamos y con la información de la medición actual.

Permite construir el mapa de forma incremental a medida que llegan nuevas mediciones

Desarrollo

  • Sea \(\text{b}_{(t)}(m_{i})\) la probabilidad actual de que la celda esté ocupada
  • Definimos \(\text{b}_{(t)}(\lnot ~m_{i})\) como la probabilidad de que la celda esté libre
  • Al ser una variable binaria:

\[ \text{b}_{(t)}(\lnot ~m_{i}) = 1 - \text{b}_{(t)}(m_{i}) \]

  • Se define el cociente entre estas dos probabilidades denominado odds:

\[ \text{O}_{(t)} = \frac{\text{b}_{(t)}(m_{i})}{\text{b}_{(t)}(\lnot ~m_{i})} = \frac{\text{b}_{(t)}(m_{i})}{1 - \text{b}_{(t)}(m_{i})} \]

  • El numerador representa la probabilidad de ocupación y el denominador, la probabilidad de que la celda esté libre

Desarrollo

Algunos ejemplos para valores de \(\text{b}_{(t)}(m_{i})\)

\[ \text{O}_{(t)} = \frac{\text{b}_{(t)}(m_{i})}{\text{b}_{(t)}(\lnot ~m_{i})} \]


\(\text{b}_{(t)} = 0.5\) \(\text{O}_{(t)} = 1\) Misma probabilidad para ambas hipótesis
\(\text{b}_{(t)} = 0.8\) \(\text{O}_{(t)} = 4\) Es 4 veces más probable que esté ocupada que libre
\(\text{b}_{(t)} = 0.2\) \(\text{O}_{(t)} = 0.25\) Es 4 veces menos probable que esté ocupada que libre

Desarrollo

Se implementará un mecanismo matemático para simplificar los cálculos utilizando el logarítmo de las probabilidades

  • Se definen las log-odds como el logaritmo del cociente entre las probabilidades de los dos estados:

\[ \log{(\text{O}_{(t)})} = \log{ \left( \frac{\text{b}_{(t)}(m_{i})}{\text{b}_{(t)}(\lnot ~m_{i})} \right) } \]

  • Ahora las probabilidades de un estado u otro están diferenciadas por el signo:
\(\text{b}_{(t)} = 0.5\) \(\text{O}_{(t)} = 1\) \(\log{(1)} = 0\) Misma probabilidad para ambas hipótesis
\(\text{b}_{(t)} = 0.8\) \(\text{O}_{(t)} = 4\) \(\log{(4)} > 0\) Es más probable que esté ocupada
\(\text{b}_{(t)} = 0.2\) \(\text{O}_{(t)} = 0.25\) \(\log{(0.25)} < 0\) Es menos probable que esté ocupada

Desarrollo

  • Desarrollando las expresiones de \(\text{b}_{(t)}(m_{i})\) y \(\text{b}_{(t)}(\lnot m_{i})\) en el cociente:

\[ \frac{ \text{b}_{(t)}(m_{i}) } { \text{b}_{(t)}(\lnot m_{i}) } = \frac{ p(m_{i} \mid \mathbf{z}_{1:t}, \mathbf{x}_{1:t}) } { p(\lnot m_{i} \mid \mathbf{z}_{1:t}, \mathbf{x}_{1:t}) } = \frac{ \eta_{t} } { \eta_{t} } \frac{ p(\mathbf{z}_{t} \mid \mathbf{x}_{t}, m_{i}) } { p(\mathbf{z}_{t} \mid \mathbf{x}_{t}, \lnot m_{i}) } \frac{ \text{b}_{(t-1)}(m_{i}) } { \text{b}_{(t-1)}(\lnot m_{i}) } \]

  • En este caso \(\eta_{t}\) se simplifica por lo que no hace falta calcularlo, entonces:

\[ \frac{ \text{b}_{(t)}(m_{i}) } { \text{b}_{(t)}(\lnot m_{i}) } = \frac{ p(\mathbf{z}_{t} \mid \mathbf{x}_{t}, m_{i}) } { p(\mathbf{z}_{t} \mid \mathbf{x}_{t}, \lnot m_{i}) } \frac{ \text{b}_{(t-1)}(m_{i}) } { \text{b}_{(t-1)}(\lnot m_{i}) } \]

Desarrollo

  • Aplicamos logaritmo a ambos lados y se define \(l_{t}^{(i)}\) como:

\[ l_{t}^{(i)} = \log{\left(\frac{\text{b}_{(t)}(m_{i})}{\text{b}_{(t)}(\lnot ~m_{i})}\right)} = \log{\left( \frac{ p(\mathbf{z}_{t} \mid \mathbf{x}_{t}, m_{i}) } { p(\mathbf{z}_{t} \mid \mathbf{x}_{t}, \lnot m_{i}) } \frac{ \text{b}_{(t-1)}(m_{i}) } { \text{b}_{(t-1)}(\lnot m_{i}) } \right)} \]

  • Por propiedad de los logaritmos

\[ l_{t}^{(i)} = \log{\left( \frac{ p(\mathbf{z}_{t} \mid \mathbf{x}_{t}, m_{i}) } { p(\mathbf{z}_{t} \mid \mathbf{x}_{t}, \lnot m_{i}) } \right)} + \underbrace{ \log{\left( \frac{ \text{b}_{(t-1)}(m_{i}) } { \text{b}_{(t-1)}(\lnot m_{i}) } \right)} }_{l_{t-1}^{(i)}} = \log{\left( \frac{ p(\mathbf{z}_{t} \mid \mathbf{x}_{t}, m_{i}) } { p(\mathbf{z}_{t} \mid \mathbf{x}_{t}, \lnot m_{i}) } \right)} + l_{t-1}^{(i)} \]

Desarrollo

  • La expresión queda:

\[ l_{t}^{(i)} = \log{\left( \frac{ p(\mathbf{z}_{t} \mid \mathbf{x}_{t}, m_{i}) } { p(\mathbf{z}_{t} \mid \mathbf{x}_{t}, \lnot m_{i}) } \right)} + l_{t-1}^{(i)} \]

  • Si quisieramos recuperar la probabilidad original:

\[ \text{b}_{(t)}(m_{i}) = 1 - \frac{1} { 1 + \exp({l_{t}^{(i)}}) } \]

  • Por lo tanto, en la medida que podamos evaluar \(\frac{ p(\mathbf{z}_{t} \mid \mathbf{x}_{t}, m_{i})} {p(\mathbf{z}_{t} \mid \mathbf{x}_{t}, \lnot m_{i})}\) podremos realizar la actualización de la probabilidad \(\text{b}_{(t)}(m_{i})\)

Desarrollo

Modelos de medición

Modelo directo Conociendo el estado del entorno \(m_{i}\) y el estado actual \(\mathbf{x}_{t}\) Qué medición \(\mathbf{z}_{t}\) se espera tener \(p(\mathbf{z}_{t} \mid \mathbf{x}_{t}, m_{i})\) o \(p(\mathbf{z}_{t} \mid \mathbf{x}_{t}, \lnot m_{i})\)
Modelo inverso Conociendo la medición del sensor \(\mathbf{z}_{t}\) y el estado actual \(\mathbf{x}_{t}\) Qué estado de la celda \(m_{i}\) se espera tener \(p(m_{i} \mid \mathbf{z}_{t}, \mathbf{x}_{t})\) o \(p(\lnot m_{i} \mid \mathbf{z}_{t}, \mathbf{x}_{t})\)
  • Tanto el término \(\frac{ p(\mathbf{z}_{t} \mid \mathbf{x}_{t}, m_{i})} {p(\mathbf{z}_{t} \mid \mathbf{x}_{t}, \lnot m_{i})}\) utiliza el modelo directo


Para construir el mapa nos interesa el modelo inverso, convertir cada medición en evidencia sobre las celdas.

Desarrollo

  • Se aplica nuevamente la regla de Bayes, ahora para relacionar:

\[ p(m_{i} \mid \mathbf{z}_{t}, \mathbf{x}_{t}) = \frac{ p(\mathbf{z}_{t} \mid \mathbf{x}_{t}, m_{i}) ~p(m_{i} \mid \mathbf{x}_{t}) } { p(\mathbf{z}_{t} \mid \mathbf{x}_{t}) } \qquad p(\lnot m_{i} \mid \mathbf{z}_{t}, \mathbf{x}_{t}) = \frac{ p(\mathbf{z}_{t} \mid \mathbf{x}_{t}, \lnot m_{i}) ~p(\lnot m_{i} \mid \mathbf{x}_{t}) } { p(\mathbf{z}_{t} \mid \mathbf{x}_{t}) } \]

  • Dividiendo ambas expresiones, se cancela el término \(p(\mathbf{z}_{t} \mid \mathbf{x}_{t})\):

\[ \frac{ p(m_{i} \mid \mathbf{z}_{t}, \mathbf{x}_{t}) } { p(\lnot m_{i} \mid \mathbf{z}_{t}, \mathbf{x}_{t}) } = \frac{ p(\mathbf{z}_{t} \mid \mathbf{x}_{t}, m_{i}) } { p(\mathbf{z}_{t} \mid \mathbf{x}_{t}, \lnot m_{i}) } \frac{ p(m_{i} \mid \mathbf{x}_{t}) } { p(\lnot m_{i} \mid \mathbf{x}_{t}) } \]

  • Despejando para el término del modelo directo y aplicando nuevamente el logaritmo del cociente:

\[ \log{\left( \frac{ p(\mathbf{z}_{t} \mid \mathbf{x}_{t}, m_{i}) } { p(\mathbf{z}_{t} \mid \mathbf{x}_{t}, \lnot m_{i}) } \right)} = \log{\left( \frac{ p(m_{i} \mid \mathbf{z}_{t}, \mathbf{x}_{t}) } { p(\lnot m_{i} \mid \mathbf{z}_{t}, \mathbf{x}_{t}) } \right) } - \log{\left( \frac{ p(m_{i} \mid \mathbf{x}_{t}) } { p(\lnot m_{i} \mid \mathbf{x}_{t}) } \right) } \]

Desarrollo

  • Los términos \(p(m_{i} \mid \mathbf{x}_{t})\) y \(p(\lnot m_{i} \mid \mathbf{x}_{t})\) pueden simplificarse debido a que sin mediciones \(\mathbf{z}\), conocer el estado actual \(\mathbf{x}_{t}\) no aporta información a la probabilidad del estado de una celda

\[ p(m_{i} \mid \mathbf{x}_{t}) = p(m_{i}) \qquad p(\lnot m_{i} \mid \mathbf{x}_{t}) = p(\lnot m_{i}) \]

\[ \log{\left( \frac{ p(m_{i} \mid \mathbf{x}_{t}) } { p(\lnot m_{i} \mid \mathbf{x}_{t}) } \right) } = \log{\left( \frac{ p(m_{i}) } { p(\lnot m_{i}) } \right) } \]

Desarrollo

  • Definimos \(l_{0}^{(i)}\) como las log-odds de la probabilidades previas de ocupación

\[ l_{0}^{(i)} = \log{\left( \frac{ p(m_{i} \mid \mathbf{x}_{t}) } { p(\lnot m_{i} \mid \mathbf{x}_{t}) } \right) } = \log{\left( \frac{ p(m_{i}) } { p(\lnot m_{i}) } \right) } \]

  • Definimos \(l_{t,\text{inv}}^{(i)}\) como las log-odds que devuelve el modelo inverso del sensor

\[ l_{t,\text{inv}}^{(i)} = \log{\left( \frac{ p(m_{i} \mid \mathbf{z}_{t}, \mathbf{x}_{t}) } { p(\lnot m_{i} \mid \mathbf{z}_{t}, \mathbf{x}_{t}) } \right) } \]

  • Por lo tanto:

\[ \log{\left( \frac{ p(\mathbf{z}_{t} \mid \mathbf{x}_{t}, m_{i}) } { p(\mathbf{z}_{t} \mid \mathbf{x}_{t}, \lnot m_{i}) } \right)} = l_{t,\text{inv}}^{(i)} - l_{0}^{(i)} \]

Desarrollo

  • Reemplazando todos los términos en la definión de \(l_{t}^{(i)}\):

\[ \boxed{ \underbrace{ l_{t}^{(i)} }_{\text{Log-odds actual}} = \underbrace{ l_{t-1}^{(i)} }_{\text{Log-odds previas}} + \underbrace{ l_{t,\text{inv}}^{(i)} }_{\text{Modelo inverso}} - \underbrace{ l_{0}^{(i)} }_{\text{Log-odds iniciales}} } \]

  • Cada celda \(i\) tiene un valor \(l_{t}^{(i)}\) asociado que “resume” la evidencia acumulada a partir de las mediciones
\(l_{t}^{(i)} > 0\) Es más probable que esté ocupada
\(l_{t}^{(i)} < 0\) Es menos probable que esté ocupada
\(l_{t}^{(i)} = 0\) Misma probabilidad para ambas hipótesis

Desarrollo

\[ \boxed{ \underbrace{ l_{t}^{(i)} }_{\text{Log-odds actual}} = \underbrace{ l_{t-1}^{(i)} }_{\text{Log-odds previas}} + \underbrace{ l_{t,\text{inv}}^{(i)} }_{\text{Modelo inverso}} - \underbrace{ l_{0}^{(i)} }_{\text{Log-odds iniciales}} } \]

  • La actualización es una suma: Cada nueva medición aporta un incremento positivo o negativo a la evidencia acumulada

  • Se necesita un modelo inverso del sensor: Determina qué evidencia aporta una medición a cada celda, según su posición respecto al sensor

Modelo de medición inversa

  • Por cada medición de LiDAR se tiene un conjunto de puntos:

\[ \{ \begin{pmatrix} r_k & \psi_k \end{pmatrix} \} = \begin{cases} r_{\text{min}} \leq r_k \leq r_{\text{max}} \\ -\frac{\pi}{2} \leq \psi_k \leq \frac{\pi}{2} \end{cases} \]

  • Conociendo la pose actual \(\begin{bmatrix} p_x & p_y & \theta \end{bmatrix}\) se obtiene la ubicación de la medición en el mapa:

\[ \{ \begin{pmatrix} x_k & y_k \end{pmatrix} \} = \begin{cases} x_k = p_x + r_k \cos(\theta + \psi_k) \\ y_k = p_y + r_k \sin(\theta + \psi_k) \end{cases} \]

Modelo de medición inversa

Qué información se puede inferir a partir de un solo haz?

  • Región donde termina la medición (rebote)
    • La celda más cercana muy probablemente sea un obstáculo
  • Región antes de la medición
    • Si el haz recorrió una región probablemente las celdas atravesadas estaban libres de obstáculos
  • Región detrás de la medición
    • El haz no permite determinar qué hay detrás, por lo que no se pueden considerar ni libres ni ocupadas

Existe ruido, objetos pequeños, superficies reflectantes y retornos fallidos, por lo que no se trata de certezas absolutas

Modelo de medición inversa

El modelo inverso transforma las inferencias geométricas del sensor en probabilidades

\[ p(m_i \mid \mathbf{x}_{t} \mathbf{z}_{t})\]

  • Dado una celda del mapa \(m_{i}\), la posición actual \(\mathbf{x}_{t} = \begin{bmatrix} x_t & y_t & \theta_t \end{bmatrix}\) y las mediciones \(\mathbf{z}_{t} = \{ \begin{pmatrix} r_k & \psi_k \end{pmatrix} \}\)

  • Encontrar el índice \(k\) de la medición que está más en dirección de la celda \(i\)

Celda \(m_i\) Inferencia Probabilidad de ocupación
Delante de la medición \(r_k\) Libre Valor mucho menor a \(0.5\)
Detrás de la medición \(r_k\) (o fuera del campo de visión) No hay suficiente información Probabilidad previa
Muy cerca de la medición \(r_k\) Ocupada Valor mucho mayor a \(0.5\)

Modelo de medición inversa

  • Para la implementación los conceptos “delante”, “detrás” y “cerca” deberán definirse mediante tolerancias que serán parámetros del modelo inverso

  • Una medición máxima puede significar que no se detectó ningún obstáculo dentro del alcance, y no que exista un obstáculo a esa distancia

  • Sea \(r\) la distancia entre el centro de la celda y el sensor y \(r_k\) la medición correspondiente al haz \(k\) que atraviesa la celda

Celda \(m_i\) Condición Probabilidad de ocupación
Delante de la medición \(r_k\) \(r \leq r_k\) Valor mucho menor a \(0.5\)
Detrás de la medición \(r_k\) (o fuera del campo de visión) \(r > r_k + \alpha /2\) o \(r > r_{\text{max}}\) Probabilidad previa
Muy cerca de la medición \(r_k\) \(| r - r_k | < \alpha /2\) y \(r_k < r_{\text{max}}\) Valor mucho mayor a \(0.5\)

Occupancy Grid

Volviendo a la formulación del mapa

\[ l_{t}^{(i)} = l_{t-1}^{(i)} + l_{t,\text{inv}}^{(i)} - l_{0}^{(i)} \]

  • Para cada caso:
    • Celda libre: \(l_{t,\text{inv}}^{(i)} = \log(< 0.5) < 0\) y se reduce la creencia de ocupación
    • Celda ocupada: \(l_{t,\text{inv}}^{(i)} = \log(> 0.5) > 0\) y se incrementa la creencia de ocupación
    • Sin información: \(l_{t,\text{inv}}^{(i)} = l_{0}^{(i)}\) por lo que el valor almacenado no cambia

Occupancy Grid

Algoritmo

  • Sean los valores de ocupación anteriores para cada celda del mapa \(l_{t-1}^{(i)}\)

  • Dada una nueva medición del lidar \(\mathbf{z}_{t} = \{ \begin{pmatrix} r_k & \psi_k \end{pmatrix} \}\)

  • y la pose actual del robot \(\mathbf{x}_{t} = \begin{bmatrix} x_t & y_t & \theta_t \end{bmatrix}\)

  • Para cada celda del mapa \(m_i\):

    • Si la celda está en el campo de visión del sensor dada la pose \(\mathbf{x}_{t}\):
      • Evaluar el modelo inverso del sensor con \(( x_i , y_i )\) de la celda, \(\mathbf{x}_{t}\) y \(\mathbf{z}_{t}\)
      • Actualizar el valor de ocupación \(l_{t}^{(i)} = l_{t-1}^{(i)} + l_{t,\text{inv}}^{(i)} - l_{0}^{(i)}\)
    • Si no, mantener el valor anterior:
      • \(l_{t}^{(i)} = l_{t-1}^{(i)}\)

Implementación en ROS2

Recuperación de las probabilidades

  • En ROS2 se utiliza un valor porcentual entre \(0\) y \(100\) para indicar si una celda está libre u ocupada, respectivamente:

\[ {p_{t}^{(i)}} = \frac{1}{1 + \exp{\left( - l_{t}^{(i)} \right)}} \qquad 0 \leq p_{t}^{(i)} \leq 1 \]

  • Por lo tanto:

\[ {\text{occ}_{t}^{(i)}} = \text{round}(100 \cdot p_{t}^{(i)}) \]
